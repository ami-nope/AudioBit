# Privacy Policy

Effective date: 2026-04-06

This Privacy Policy applies to AudioBit, including the Windows desktop app, optional remote-control features, and optional third-party integrations.

## 1. What AudioBit Collects

AudioBit may process the following information:

- Local app data, such as settings, preferences, app logs, device selections, and audio session metadata.
- Optional Discord and Spotify authorization data needed to keep those integrations working.
- Optional remote-control session data, such as pairing codes, session IDs, device names and IDs, app names, per-app volume and mute state, and remote control commands.
- Optional Google Sheets export data, such as timestamps, device identifiers, log levels, log messages, and related export fields selected by the user.
- Standard network metadata that service providers normally receive when requests are made, such as IP address, timestamps, and basic request information.

## 2. What AudioBit Does Not Collect

AudioBit does not:

- Record or store the content of your microphone, speakers, calls, or music.
- Sell personal information.
- Use advertising trackers.
- Intentionally collect Discord message content, server message content, or similar chat content for the Discord integration.

## 3. How AudioBit Uses Information

AudioBit uses information to:

- Provide audio-control and device-routing features.
- Save user preferences and restore app state.
- Support optional Discord and Spotify integrations.
- Support optional remote-control and pairing features.
- Export logs only when the user enables or triggers that feature.
- Diagnose crashes, sync failures, and service errors.

## 4. How Information Is Shared

AudioBit shares information only as needed to operate selected features:

- With Discord, when a user connects the Discord integration.
- With Spotify, when a user connects the Spotify integration.
- With AudioBit relay infrastructure, when a user uses remote-control features.
- With Google services, when a user enables or triggers Google Sheets log export.
- With infrastructure and hosting providers that help operate the app or related services.

AudioBit does not sell personal information to advertisers or data brokers.

## 5. Storage and Retention

- Local settings, logs, and integration state are stored on the user's device until removed by the user, cleared by the app, or deleted during uninstall or data cleanup.
- Discord and Spotify authorization state is stored locally and protected using Windows user-level encryption.
- Remote session data is intended to be temporary and is kept only as needed to operate the session and maintain service reliability.
- Data exported to Google Sheets remains subject to the user's Google account and spreadsheet settings until the user deletes it.

## 6. User Choices and Deletion

Users can:

- Disconnect Discord or Spotify inside AudioBit and revoke access from the relevant provider account settings.
- Disable remote-control or Google Sheets export features at any time.
- Delete local AudioBit data by removing `%LOCALAPPDATA%\AudioBit`.
- Request deletion of data controlled by AudioBit by contacting the project through the support link below.

## 7. Security

AudioBit uses reasonable technical and organizational measures to protect information it stores or processes. No system can be guaranteed to be completely secure.

## 8. Children's Privacy

AudioBit is not intended for children under 13.
